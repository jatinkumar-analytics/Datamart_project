# Source Data

The project uses seven synthetic, clean domain exports:

```text
01_commerce_events.csv
02_procurement_lines.csv
03_shipment_lines.csv
04_inventory_daily.csv
05_order_lifecycle.csv
06_promotion_coverage.csv
07_workforce_events.csv
```

The CSV files are generated by `generate_bharatmart_sources.py`. They intentionally include repeated descriptive attributes so conformed Dimensions can be derived while the final Facts remain separate by business-process grain.

`BUS_MATRIX_9x13.csv` maps nine business processes to thirteen conformed Dimensions.

The source package is development-scale and contains no real personal or company data. Data cleaning is outside this project's scope; the source is treated as clean and correctly typed for dimensional-modelling practice.
